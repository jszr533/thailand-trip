📋 入境须知 · 必带清单

🛂 入境要求
  • 中泰永久互免签证，单次可停留 ≤30 天
  • 护照有效期须 ≥6 个月，至少 1 页空白页
  • 须持返程/续程机票备查（离境凭证）
  • 建议备酒店预订单；可能抽查现金（个人≥2万 / 家庭≥4万泰铢，或等值外币；部分使馆提示个人≥1万亦可作为参考，建议就高携带）
🎒 必带物品
🛂 护照（≥6个月） 💵 现金（个人≥2万铢） ✈️ 往返机票单 🏨 酒店预订单 🔌 转换插头 ☂️ 折叠伞 🧴 防晒/驱蚊 💊 常用药 🩴 拖鞋（涉水/酒店） 🧥 一次性雨衣 🎒 防水袋（护手机） 👕 换洗衣物 📱 流量卡（泰国 eSIM/本地 SIM）

🚇 曼谷/清迈 公共交通指南

🟩 BTS 轻轨（天铁）
  • 两条线：素坤逸线（Mo Chit ↔ Samrong）与是隆线（National Stadium ↔ Bang Wa），覆盖暹罗/素坤逸/是隆等主要商圈
  • 自助售票机收纸币+硬币（部分机型可能只收硬币，但多数新机型已支持纸币）；也有人工售票窗口
  • 推荐办 Rabbit Card（兔子卡）— 储值卡，刷卡进站免排队，余额可退；也有 BTS 一日通票（One Day Pass），当日无限次乘坐，约 150 泰铢
  • BTS 与 MRT 不同公司运营，票不互通，换乘需出站再进站另买票
  • 车厢内禁止饮食（含喝水、吃口香糖），违者罚款
🟦 MRT 地铁
  • 蓝线主线：Hua Lamphong（华南蓬·唐人街/大皇宫） ↔ 乍都乍周末市集 ↔ Bang Sue
  • 单程票为圆形塑料代币，进站刷卡、出站投币回收
  • 可直接刷 Visa/Mastercard 信用卡（contactless）进站，免购票
  • 黄线 & 粉线新线到东/北郊区，日常游客用得少
  • 车厢内也禁止饮食，空调很足建议带薄外套
🚄 Airport Rail Link 机场快线
  • 素万那普机场 → 市区（Makkasan / Phaya Thai），约 25-30 分钟，45 泰铢起
  • 到 Phaya Thai 可换乘 BTS 素坤逸线，到 Makkasan 可换乘 MRT 蓝线
  • 运营时间 约 06:00–24:00，红眼航班落地只能打车
  • 廊曼机场没有机场快线，到市区可坐 SRTC 红线火车（约 1 小时）或 Grab 打车
  • 夜间落地推荐 Grab：清迈机场到古城约 40-60 泰铢，曼谷素万那普到市区约 300-380 泰铢
💡 通用提醒：所有泰国公共交通禁止携带榴莲（气味重）；高峰时段（7:00-9:00 / 17:00-19:00）BTS/MRT 极挤；Grab 打车注意堵车，加价（surge pricing）时段可达 2-3 倍；清迈市内无 BTS/MRT，主要靠 Grab / 双条车（红顶，古城内约 30 泰铢/人） / 租摩托车。

📲 添加到主屏幕

把行程单存到主屏幕，以后像 App 一样点开就能看，全屏无浏览器地址栏～ 选择你的设备：

iPhone / iPad
⚠️ 必须用自带的 Safari 浏览器，微信/Chrome 不行
  1. 第一步：复制链接，在 Safari 中打开本页面
  2. 第二步：点底部工具栏中间的 分享 图标 ⬆️
  3. 第三步：向下滑，找到 「添加到主屏幕」（图标是个➕）
  4. 第四步：点右上角 「添加」，桌面出现图标 ✅
如果分享菜单里找不到「添加到主屏幕」，请确认你用的是 Safari 浏览器，不是微信/Chrome。
安卓（Chrome / Edge / 三星浏览器）
  1. 用 Chrome 等浏览器打开本页面
  2. 点右上角 ⋮ 菜单
  3. 选 “安装应用” 或 “添加到主屏幕”（Install app / Add to Home screen）
  4. 点 安装 / 添加，桌面即出现图标 ✅
若地址栏右侧直接出现 “安装” 图标（⬇️ 或 ⊕），点它可一键安装，无需进菜单。
电脑桌面（Windows / macOS · Chrome / Edge）
  1. 用 Chrome 或 Edge 打开本页面
  2. 点右上角 ⋮ 菜单 → 应用 → 将此站点安装为应用
  3. （或地址栏右侧出现 ⊕ 安装 图标，点它）
  4. 确认后会在桌面 / 开始菜单生成独立图标 ✅
装成应用后，下次从桌面图标打开即为全屏无地址栏的“类 App”窗口。
