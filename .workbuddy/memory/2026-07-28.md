## 泰国行程网页「打开特别慢」诊断与修复

**根因**：`index.html` 引用了两个国内被墙/极慢的外部资源：
1. `https://cdn.tailwindcss.com`（Tailwind Play CDN，浏览器实时编译，慢）
2. `https://fonts.googleapis.com`（Google Fonts，国内完全屏蔽，页面卡等超时数秒才渲染）

**修复方案**：
- 用 Tailwind CLI（v3）把页面用到的工具类编译成**同源本地 `tailwind.css`**（13KB minify）
- 移除 Google Fonts，字体改为**系统字体栈**（PingFang SC / Microsoft YaHei 等）
- 页面从此零外部请求

**关键部署坑（重要）**：本仓库 GitHub Pages 实际以**根目录 `index.html`** 为源（不是 `outputs/` 也不是 `public/`，尽管三份内容相同）。三处 `index.html`（根 / outputs / public）必须同步修改，否则改了 outputs/public 线上（根源）仍慢。本次根目录缺 `tailwind.css` 与图标/manifest/sw.js，已一并补齐。

**验证**：线上 `jszr533.github.io/thailand-trip/` 探测确认外部依赖=0、tailwind.css HTTP 200。已 push（main → e2c57dc）。

**环境注意**：沙箱到 `github.com:443` 的 git 推送网络极不稳定（api.github.com 通但 github.com 超时），需多次重试才能成功。
